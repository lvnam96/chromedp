# Security Policy

## Supported Versions

We support the latest released version of `chromedp`. We recommend always
upgrading to the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Instead, report security vulnerabilities via [GitHub Security Advisories][advisories].
Click **"Report a vulnerability"** to open the advisory form.

We will acknowledge your report within 5 business days, and aim to release a
fix within 30 days for confirmed vulnerabilities. We will keep you informed
throughout the process.

[advisories]: https://github.com/chromedp/chromedp/security/advisories/new
